# Bfresh - Online Fruit Juice Ordering System

Bfresh is an e-commerce web platform developed using PHP and MySQL for a fresh fruit juice business. It allows customers to browse juice catalogs, place orders, make online payments, and track order statuses, while providing an administrative dashboard to manage inventory, products, orders, and sales promotions.

---

## Key Features

### Customer Features
- **Browse & Search:** Explore fresh juice products, category listings, and special offers.
- **Shopping Cart & Checkout:** Add products to cart, place orders as registered users or guests.
- **User Dashboard:** View order history, order status updates, and manage user profile details.
- **Customer Feedback & Reviews:** Submit product reviews and platform ratings.

### Admin Features
- **Product & Inventory Management:** Add, update, view, or remove products and track stock levels.
- **Order Management:** View incoming orders, update processing statuses, and manage fulfillment.
- **Promotions & Flash Sales:** Configure and highlight active promotions and flash sales.

---

##  Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP (Apache & MySQL)
